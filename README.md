# ML: базовый Python. Объединение чеков магазинов

Учебная задача по базовому Python и pandas: собрать «чеки» магазинов из папки в один отсортированный CSV-файл.

## Задача

Магазины присылают отчёты о продажах в виде CSV-файлов. Вместе с чеками в папке лежат лишние файлы, а в некоторых чеках есть лишние столбцы.

Нужно написать функцию `process_files(src_folder, dest_folder)`, которая:

1. выбирает из `src_folder` только чеки, имя которых соответствует шаблону `ГГГГ-ММ-ДД-ЧЧ-ММ-idмагазина.csv`;
2. читает их (разделитель во входных файлах `;`) и оставляет столбцы `date`, `product`, `store`, `cost`;
3. объединяет все чеки в одну таблицу и сортирует её по `date`, затем по `product`;
4. сохраняет результат в `dest_folder/combined_data.csv` (разделитель на выходе `,`).

Правильность даты в имени файла не проверяется: `2023-02-30-…csv` считается чеком.

## Как это работает

| Шаг | Что делает | Чем |
|---|---|---|
| Отбор файлов | оставляет только имена по шаблону | регулярное выражение `^\d{4}-\d{2}-\d{2}-\d{2}-\d{2}-\d+\.csv$` |
| Чтение | читает файл с разделителем `;` | `pd.read_csv(..., sep=';')` |
| Очистка | отбрасывает лишние столбцы, например `id` | `df[COLUMNS]` |
| Объединение | склеивает таблицы друг под другом | `pd.concat(..., ignore_index=True)` |
| Сортировка | по дате, затем по продукту | `sort_values(['date', 'product'], kind='stable')` |
| Запись | создаёт папку и сохраняет CSV с запятой, без индекса | `os.makedirs`, `to_csv(..., sep=',', index=False)` |

Дата намеренно остаётся строкой, а не переводится в `datetime`: в данных встречается несуществующая дата `2023-02-30`, а формат `ГГГГ-ММ-ДД` и так правильно сортируется как текст.

## Структура репозитория

| Файл | Назначение |
|---|---|
| `solution.py` | функция `process_files` |
| `check.py` | скрипт проверки: скачивает данные и эталон, запускает решение, сравнивает результат |

## Запуск

Нужен Python 3 и pandas. Пакеты удобнее ставить в виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install pandas
python check.py
```

Если всё верно, скрипт напечатает:

```
Поздравляем, проверки пройдены! (30, 4)
```

Результат работы функции сохраняется в `comb_reports/combined_data.csv`.

### Использование в своём коде

```python
from solution import process_files

process_files('reports-main', 'comb_reports')
```

## Типичные ошибки

| Симптом | Причина |
|---|---|
| `KeyError: 'date'` | не указан `sep=';'` при чтении |
| Лишний столбец `Unnamed: 0` | забыт `index=False` при записи |
| `FileNotFoundError` при записи | не создана папка назначения |
| Больше 30 строк | в выборку попали файлы, не подходящие по имени |
| Порядок строк не совпал | нет сортировки по `date`, затем по `product` |
