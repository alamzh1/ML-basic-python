# Кейс 3. Метрики активности пользователей

Учебная задача на чистом Python (только стандартная библиотека). По данным о регистрациях и входах на платформу нужно посчитать retention, rolling retention, lifetime, churn rate, а также MAU, WAU и DAU.

## Данные

| Файл | Столбцы | Содержимое |
|---|---|---|
| `registrations.csv` | `user_id;registration_date` | 1000 пользователей, регистрации с января по декабрь 2021 |
| `entries.csv` | `user_id;entry_date` | ~20 700 входов. Один пользователь может зайти несколько раз за день |
| `metrics.txt` | — | эталонные ответы курса, по одному на строку |

Разделитель в CSV — `;`. Повторные входы за один день считаются одним входом.

## Метрики

«День N» — это N дней после регистрации. День 0 — сам день регистрации.

| Переменная | Что считается | Как |
|---|---|---|
| `retention_15_day` | Retention 15-го дня, когорта январских регистраций, % | доля когорты, у которой есть вход ровно на 15-й день |
| `rolling_retention` | Rolling retention 30-го дня, та же когорта, % | доля когорты, у которой есть вход на 30-й день **или позже** |
| `lifetime` | Lifetime по всем пользователям | сумма n-day retention (в долях) по всем дням начиная с 0. Это то же самое, что «число дней с входом» в среднем на пользователя |
| `churn_29` | Churn rate 29-го дня по всем пользователям, в долях | `1 − rolling retention 29-го дня / 100`: доля тех, кто не заходил ни на 29-й день, ни позже |
| `dec_mau` | MAU за декабрь 2021 | уникальные пользователи с входом 1–31 декабря |
| `dec_wau` | WAU за последнюю неделю | уникальные пользователи с входом 25–31 декабря |
| `dec_dau` | DAU за последний день | уникальные пользователи с входом 31 декабря |
| `avg_mau` | средний MAU | среднее по 12 календарным месяцам |
| `avg_wau` | средний WAU | среднее по календарным неделям ISO (с понедельника). Неделя 1–3 января 2021 относится к 53-й неделе 2020 года, всего 53 недели |
| `avg_dau` | средний DAU | среднее по всем дням, в которые были входы (365 дней) |

Дробные результаты округлены до 5 знаков, как требует задание.

## Файлы

| Файл | Назначение |
|---|---|
| `solution.py` | расчёт всех метрик (функция `calculate`), запускается из консоли |
| `check.py` | проверка: сравнивает каждую метрику с `metrics.txt` так же, как ячейки проверки в курсе (`==` с `float(answer)`) |

## Запуск

Нужен только Python 3, сторонние пакеты не используются.

```bash
cd ~/Desktop/ML/Кейс_3
python3 solution.py
```

Вывод:

```
retention_15_day   54.65116
rolling_retention  29.06977
lifetime           14.804
churn_29           0.509
dec_mau            133
dec_wau            84
dec_dau            47
avg_mau            102.58333
avg_wau            89.86792
avg_dau            40.5589
```

Пути к другим файлам можно передать аргументами: `python3 solution.py путь/registrations.csv путь/entries.csv`.

### Проверка

```bash
python3 check.py
```

Если все 10 метрик совпали с эталоном, последняя строка вывода:

```
Поздравляем, все проверки пройдены!
```
