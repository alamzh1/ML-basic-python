# ML: базовый Python. Объединение чеков магазинов

Учебная задача по базовому Python и pandas: собрать «чеки» магазинов из папки в один отсортированный CSV-файл.

## Задача

Магазины присылают отчёты о продажах в виде CSV-файлов. Вместе с чеками в папке лежат лишние файлы, а в некоторых чеках есть лишние столбцы.

Нужно написать функцию `process_files(src_folder, dest_folder)`, которая:

1. выбирает из `src_folder` только чеки, имя которых соответствует шаблону `ГГГГ-ММ-ДД-ЧЧ-ММ-idмагазина.csv`;
2. читает их (разделитель во входных файлах `;`) и оставляет столбцы `date`, `product`, `store`, `cost`;
3. объединяет все чеки в одну таблицу и сортирует её по `date`, затем по `product`;
4. сохраняет результат в `dest_folder/combined_data.csv` (разделитель на выходе `,`).

Правильность даты в имени файла не проверяется: `2023-02-30-…csv` считается чеком.

## Структура репозитория

| Путь | Назначение |
|---|---|
| `Кейс_1/solution.py` | функция `process_files` |
| `Кейс_1/check.py` | скрипт проверки: скачивает данные и эталон, запускает решение, сравнивает результат |
| `Кейс_2/` | следующий кейс (пока пусто) |
| `Кейс_3/` | следующий кейс (пока пусто) |

## Запуск

Нужен Python 3 и pandas. Пакеты удобнее ставить в виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install pandas
cd Кейс_1
python check.py
```

Если всё верно, скрипт напечатает:

```
Поздравляем, проверки пройдены! (30, 4)
```

Результат работы функции сохраняется в `Кейс_1/comb_reports/combined_data.csv`.
