# Кейс 2. Отчёт о должниках по рассрочкам

Учебная задача по базовому Python: по данным о студентах и их рассрочках найти тех, кто просрочил платежи, и сохранить отчёт в текстовый файл.

## Задача

В Google Sheets есть таблица из трёх листов:

| Лист | Столбцы |
|---|---|
| `Лист1` | `student_id`, `student_name`, `installment` (`Y` — есть рассрочка, `N` — нет) |
| `Лист2` | `student_id`, `last_payment_date` (последний полученный платёж), `expected_payment_date` (следующий ожидаемый платёж) |
| `Лист3` | `student_id`, `already_payed_amount` (уже выплачено), `left_to_pay` (осталось выплатить), `one-time_payment` (размер одного платежа), `installment_amount` (вся сумма рассрочки) |

Нужно написать функцию `generate_report(sheet1, sheet2, sheet3)`, которая принимает данные трёх листов (списки словарей, как их возвращает `get_all_records()` из `gspread`) и сохраняет отчёт в `student_debt_report.txt` в формате:

```
Студент Иванов У.У. - долг 100000 рублей
Студент Петров Е.Е. - долг 250000 рублей
```

Условия:

- долг считается на **1 марта 2023 года**, а не на сегодняшний день;
- платежи вносятся раз в **183 дня**, отсчёт идёт от `expected_payment_date`;
- если студент пропустил несколько платежей, долг равен сумме всех пропущенных. Пример: платёж ожидался 3 февраля 2022, тогда к 1 марта 2023 пропущено три платежа (февраль 2022, август 2022, февраль 2023).

## Как считается долг

Для каждого студента с рассрочкой (`installment == 'Y'`):

1. `days = 01.03.2023 − expected_payment_date`;
2. если `days < 0`, срок ещё не наступил и долга нет; иначе пропущено `days // 183 + 1` платежей;
3. `долг = min(пропущено × one-time_payment, left_to_pay)`. Долг не может быть больше остатка по рассрочке, поэтому у тех, кому осталось заплатить меньше, чем набежало платежей, долг равен `left_to_pay`;
4. в отчёт попадают студенты с долгом больше нуля, в порядке `Лист1`.

На текущих данных должников 166.

## Файлы

| Файл | Назначение |
|---|---|
| `solution.py` | функция `generate_report` и загрузка данных из Google Sheets или Excel; запускается из консоли |
| `check.py` | проверка: строит отчёт по `Installments.xlsx` и сравнивает с эталоном `student_debt.txt` |
| `Installments.xlsx` | выгрузка той же Google-таблицы (листы `Лист1`–`Лист3`), чтобы запускать без доступа к API |
| `student_debt_report.txt` | результат, появляется после запуска |

## Запуск

Нужен Python 3 и pandas с openpyxl. Виртуальное окружение `.venv` лежит в корне репозитория (то же, что и для кейса 1):

```bash
cd ~/Desktop/ML
python3 -m venv .venv            # если окружения ещё нет
source .venv/bin/activate
pip install pandas openpyxl
cd Кейс_2
```

### Из локального Excel (по умолчанию)

```bash
python solution.py
```

Вывод:

```
Отчёт сохранён в student_debt_report.txt, должников: 166
```

Другой файл можно передать через `--excel путь/к/файлу.xlsx`.

### Проверка

```bash
python check.py
```

Скрипт скачивает эталон и сравнивает его с отчётом так же, как проверка в курсе (через `pd.read_csv`). При совпадении он напечатает:

```
Поздравляем, проверки пройдены! (165, 1)
```

(165, а не 166: `read_csv` считает первую строку отчёта заголовком.)
